# examples/

Worked end-to-end examples. Read these AFTER the install is done and the
pipeline boots.

| File | What it shows |
|---|---|
| `01_goblin_warrior.md` | Mini, resin, ~32mm. The canonical first run. |
| `02_stone_watchtower.md` | Terrain, FDM, ~100mm. Different kind, different printer. |
| `03_batch_scatter.md` | Generate 8 scatter pieces (barrels, crates, ruined walls) in one go. |

Each example contains:
1. The user's natural-language prompt
2. The Claude conversation that turned it into FLUX prompts
3. The intermediate concept image
4. The Sparc3D mesh output
5. The Blender-cleaned STL
6. The slicer advisory
7. Print parameters used + a photo of the result (after you print yours)
