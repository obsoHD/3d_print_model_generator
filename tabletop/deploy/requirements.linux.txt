# Curated Linux deps for the ACTIVE engines (Hunyuan single/mv, TripoSG, parametric).
# Versions mirror the proven Windows env; torch is cu128 because Blackwell (RTX 5090,
# sm_120) has NO kernels in cu124 — CUDA 12.8+ is mandatory.
#
# torch/torchvision are installed separately in the Dockerfile from the cu128 index:
#   pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
#
# The Pixal3D Windows CUDA wheels (cumesh_vb/drtk/natten/nvdiffrast/o_voxel/flex_gemm_ap)
# are intentionally OMITTED — Pixal3D is installed-but-unused; on Linux those build from
# source if ever needed. diso (TripoSG DMC) builds from source on first run.
